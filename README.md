# Computational Biology

This repository contains code and data for a species distribution modeling (SDM) analysis and some ML methods: Image classification, logistic regression, random forest, PCA, and K means clustering. 

## Repository structure

- `data/`  
  Empirical data used as inputs to the model. 

- `scripts/`  
  R scripts used for data processing and model construction.

## Notes

This repository contains files from a computational biology class.
